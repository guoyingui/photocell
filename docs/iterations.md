# 迭代记录

按原路线顺序实施，界面面向电脑浏览器，操作使用鼠标与键盘。代码完成与真实素材验收分别记录。

| 顺序 | 功能 | 当前实现 |
| --- | --- | --- |
| 1 | 双图对比 | 两张并排、同步缩放和平移、固定参考图、分别标记，支持只读浏览 |
| 2 | 明确导出范围 | 全库最终收藏、成员收藏、当前筛选收藏、手动选区；执行前显示范围和数量 |
| 3 | 完善大图操作 | 上一张／下一张、收藏／排除／取消标记按钮，按完整 JPG 像素计算 100%，贴合窗口 |
| 4 | 续选与操作恢复 | 按目录恢复浏览位置，常驻撤销／重做，筛选与刷新后清理失效光标、选区及预览 |
| 5 | 客户提交与确认 | 每客户数量上限、整体及单张备注、提交快照与锁定、摄影师确认和重新开放 |
| 6 | 多人意见汇总 | 共同收藏、意见冲突、至少两人收藏；保留原始意见，摄影师另存最终决定 |
| 7 | 星级、标签与后期衔接 | 单张及批量设置星级／颜色／关键词／阶段，组合筛选，下载标准 XMP ZIP |
| 8 | 纯 RAW 预览初版 | TIFF 内嵌 JPEG 提取、方向、尺寸与缓存；有 JPG 时优先 JPG，不支持的容器明确提示 |
| 9 | 电脑端使用便利性 | 系统文件夹选择、真实路径拖入添加、分享面板临时网络开关、本机二维码、预览缓存管理 |

前一轮的照片参数展示与筛选、文件名定位、连拍设置、个人浏览进度、导出历史与失败重试继续保留。

## 筛选效率迭代

本轮完成下一轮建议中的前三项，继续面向电脑浏览器：

| 顺序 | 功能 | 当前实现 |
| --- | --- | --- |
| 1 | 筛选面板整理 | 拍摄参数、客户意见、后期筛选可分别折叠；生效条件常驻显示，可逐项清除；浏览器记住布局 |
| 2 | 排序与筛选预设 | 时间／文件名／星级双向排序，保留连拍分组；预设保存条件与排序，按照片库或访客身份隔离 |
| 3 | 批量文件名匹配 | 粘贴或导入 TXT／CSV，支持选列与标题识别；精确匹配、同名确认、未找到提示、加入选区或收藏 |

预设存放在当前浏览器，每份最多 20 个；匹配清单每批最多 5000 行、文件不超过 2 MB。
应用预设、更改排序会清空旧选区和预览。匹配覆盖当前库全部未隐藏照片，结果会进入独立筛选条件，
导出「当前筛选中的收藏」也遵守该清单。同名冲突未确认、目录已刷新或会话已变化时不能直接操作旧结果。

自动测试覆盖预设持久化失败与身份隔离、折叠后清除条件、排序与键盘顺序一致、空清单不扩大范围、
RAW/JPG 去重、同名消歧、CSV 引号和列选择、异步导入竞争、只读／锁定限制以及导出默认范围。

本轮在 Chromium 浏览器中使用独立临时库（6 张测试 JPG）检查了折叠与逐项清除、预设保存／应用／刷新恢复、
同名确认、重复条目去重、真实 CSV 文件导入、加入选区及收藏范围，以及弹窗的 Tab 循环和 Escape 关闭。
浅色／深色主题与 1440、1024 像素宽电脑窗口均已查看；这不替代下方的真实大图库与跨设备验收。

## 多目录侧栏

主页面左侧常驻「照片目录」，可勾选多个目录、跨层级选择或粘贴多行路径添加；原来的顶栏「选择文件夹」入口移至左侧。
添加时复用服务端目录边界校验，按真实路径去重。目录列表与上次打开位置保存在当前浏览器，旧版最近目录自动迁入。
点击目录切换，当前目录下显示子文件夹筛选；首次添加打开第一个目录，已有选片工作不被添加动作中断。
移除只影响列表，不删除磁盘照片。当前目录切换／移除复用关闭检查，保留访客在线确认与分享撤销入口，移动导出期间保持当前会话。

自动测试覆盖多目录勾选、跨层级选择、路径失效与去重、取消后的异步校验、目录记忆、移除、访客确认后继续原动作、
关闭失败不继续切换，以及移动任务拦截后仍保留会话、选区和实时连接。

浏览器实际检查使用三个临时目录、6 张 JPG：批量粘贴添加、追加目录不切换当前库、目录间标记与筛选隔离、
目录离线后保持原视图及恢复重试、移除当前目录后照片仍在、刷新恢复目录列表和最后位置。
已查看 1440 像素深色布局与 1024 像素浅色布局；系统原生目录窗口与真实大图库仍待验收。

## 实际使用范围

- XMP 使用 Adobe 定义的星级、标签和关键词字段。颜色显示取决于软件标签设置，阶段同时写成关键词。
  ZIP 下载不会改动已有 XMP；合并到已有后期流程前保留原 sidecar。尚未在真实修图软件中验收。
- RAW 支持范围按容器结构判断，标准 TIFF JPEG 偏移／单段 JPEG strip 可提取；不做 RAW 像素解码。
  CR3 等其他容器暂不支持。人工 TIFF 测试不能证明所有 CR2／NEF／ARW／DNG 相机型号兼容。
- 浏览器常只提供拖入目录的名字，不能获得完整路径。仅真实 `file://` 路径能直接加入待添加；名字命中候选仍需确认。
- 系统目录窗口出现在服务所在电脑；Linux 需图形桌面与 zenity／kdialog。远程管理使用页面目录浏览器。
- 默认不开局域网分享。普通启动后的界面分享使用独立端口，关闭后本机任务继续。
  `--share` 启动保留既有服务端口与部署行为，由启动参数控制，关闭服务结束访问。
